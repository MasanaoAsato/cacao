# playful-doodle の装飾素材

`playful-route` 系統が使う手描き調の装飾素材を置く。登録は
[`src/theme/motifAssets.ts`](../../../theme/motifAssets.ts) が正本で、viewBox と
`aspect` の一致は `src/theme/motifAssets.test.ts` が検証する。

## 共通の制約

- 透明背景とし、線の太さを含めた外接範囲を viewBox 内に収める。
- 単色（`#111827`）で描く。実際の色は `recolor: "mask"` により配色から与えられる。
- SVG 内に文字描画・スクリプト・外部参照を置かない。`<title>` は素材名のみ。
- 外部画像の切り抜きやトレースは使わず、パスを独自に構成する。

## 制作経緯

既存素材（`playful-bag` / `playful-burst` / `playful-squiggle` / `playful-sun`）の
制作経緯は記録が残っていないため、ここには書かない。

### playful-footprints.svg（20.11 で追加）

- viewBox `0 0 150 200`、`aspect` 3:4。表紙のかばん用予約領域（18 × 24mm）に置く。
- 右上へ進むようにずらした左右2つの靴底。左足の輪郭を手で起こし、中心線
  `x = 42` で鏡映したうえで `(+66, -76)` 平行移動して右足とした。
- 靴底模様やブランド記号は入れず、丸みのある大きな面だけで構成する。18 × 24mm
  でも足跡と読めることを基準に、くびれ（土踏まず）の深さを決めた。
- 外部素材は使用していない。座標は Claude Code（Claude Opus 5）の補助で
  起こし、形と収まりは実寸のE2E描画で確認した。

### playful-curved-arrow.svg（20.11 で追加）

- viewBox `0 0 300 100`、`aspect` 3:1。表紙のきらめき用予約領域（24 × 12mm）の
  上下中央と、本文下部の装飾領域（24 × 8mm）に置く。
- 左から右へ緩く曲がる3次ベジェ1本と、終点の接線に対して ±30° で開いた矢じり。
  線幅 12、丸い線端と接合を使い、既存の `playful-squiggle` と調子をそろえた。
- 24 × 8mm でも矢じりと曲線が区別できるよう、矢じりの長さを 34 単位（約2.7mm）
  とした。
- 外部素材は使用していない。座標は Claude Code（Claude Opus 5）の補助で
  起こし、形と収まりは実寸のE2E描画で確認した。

足跡と矢印はいずれも装飾であり、移動手段・実際の方角・予定の接続線としては
扱わない。
